# どうぶつ詰めしょうぎ

動物将棋の詰将棋のウェブアプリを作ってください。
小学生が楽しめるぐらいのレベルから、大人まで楽しめるものを入れていってください。
難易度の段階を示してください。

## メモ（作った側）

- 問題は、どうぶつしょうぎ（田中 2009 の規則）の到達可能な全局面の完全解析から採掘した詰み局面から選んだ。
  3手詰め以上は、詰将棋の「完全作」（最後の王手以外は答えが1とおり・余詰なし・駒余りなし）。
  王手は「相手がなにもしなければ次にライオンを取れる手」（田中 2009 の定義）。
- 問題集 `puzzles.js` は自動生成（生成スクリプトは研究リポジトリ側 `2026_dobutsushogi/papers/T1-interesting-mates/make_web_puzzles.py`）。手で編集しない。
- 級（むずかしさ）: ひよこ級 1手詰め → にわとり級 3手 → ぞう級 5手 → きりん級 7〜9手 → ライオン級 11〜13手 → 名人級 15〜19手 → 特別問題 21〜23手。
- 追加の依頼（「23手詰めもあるのでは？」）: 完全解析でいちばん長い 21・23 手詰め（田中 2009 の表 3・図 10）は、どれも余詰めがあり完全作ではない。
  そこで「特別問題」として入れ、アプリに詰み探索（core.js の nAtt / mDef）を持たせて、詰む王手ならどれでも正解、相手はいちばん長く逃げる、にした。
- オリジナル版 v1/ は最初に公開した版（6段階・56問）を core.js / puzzles.js ごと保存している。
- 駒は絵文字（元のゲームのイラストは使わない）。
