# テトリス

定番の落ちものパズル「テトリス」。

10×20 の盤に、7種類のミノ（I・O・T・S・Z・J・L）が上から落ちてくる。
左右に動かして回転させ、ヨコ1列をすきまなく埋めるとその行が消えて得点になる。
一度に複数行消すと高得点（4行同時消し＝テトリス）。連続で消すと連鎖ボーナス。
上まで積み上がって新しいミノが置けなくなったらゲームオーバー。
ハイスコアは記録される。

## 操作
- キーボード: ← → 移動 / ↑ 回転 / ↓ ソフトドロップ / Space ハードドロップ / C ホールド / P 一時停止
- タッチ: 画面下のボタン（長押しで連続移動）、盤面タップで回転・下スワイプで落下

## 特徴（デラックス版）
- 7-bag ランダマイザ（偏りの少ないミノ出現）
- ゴースト表示（落下先プレビュー）
- ホールド（1個ストック）／NEXT 表示
- レベルで落下速度アップ、ライン消去エフェクト・効果音・振動

## 構成
- `core.js` … 盤・ミノ・衝突・回転・ライン消去・得点などの純粋ロジック（DOM非依存）
- `index.html` … デラックス版 UI（`core.js` を読み込み）
- `v1/index.html` … 最初に作ったオリジナル版（1ファイル完結）
- `test.js` … core のユニットテスト（`node test.js`）
- `smoke.js` … UI 配線のスモークテスト（`node smoke.js`）
