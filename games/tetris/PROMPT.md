# テトリス

おなじみのテトリス。

10×20の盤に、7種類のテトロミノ（I/O/T/S/Z/J/L）が上から落ちてくる。
左右に動かし、回転させて、すき間なく積んでいく。
ヨコ一列がすべて埋まると、その列が消えて得点になる。
一度に複数列（最大4列＝テトリス）消すほど高得点。
消したライン数が増えるとレベルが上がり、落下が速くなる。
NEXT（次のピース）とHOLD（1個キープ）あり。ゴースト表示で着地点がわかる。
ブロックが天井までつかえたらゲームオーバー。ハイスコアは記録される。

操作：
- スマホ … 画面下のボタン（◀ ▶ 回転 ▼そっと ⤓ストン）／盤をタップで回転・スワイプで移動
- キーボード … ← → ↓、↑（回転）、スペース（一気に落下）、C（ホールド）
